# API Sentinel Scanner Engine

The scanning engine runs automated security vulnerability checks against targeted API endpoints with explicit authorization.

## Security Rules Covered
- **SEC-BOLA-01**: Broken Object Level Authorization
- **SEC-AUTH-01**: Broken Authentication & JWT Signature Validation
- **SEC-RATE-01**: Unrestricted Rate Limiting
- **SEC-HEAD-01**: Missing Defensive Security Headers
- **SEC-INJ-01**: Injection Attack Vector Auditing
